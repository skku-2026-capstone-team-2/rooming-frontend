# rooming 기획문서

> 초기 기능명세서 초안 형식을 유지하되, **현재 프로젝트(프론트엔드) 구현 상황을 반영**해 갱신한 문서입니다.
> 최종 갱신일: 2026-06-20

상태 범례: ✅ 구현 완료 · 🟡 부분 구현 · ❌ 미구현 · ➖ 해당 없음(정책상 제외)

---

## 서비스 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | SKKU-Zip |
| 요약 | 대학생을 위한 AI 기반 3D 자취방 탐색 및 생활권 분석 플랫폼 |
| 문제정의 | 부동산 정보의 파편화, 2D 사진 왜곡, 주변 인프라 및 통학 동선 파악의 어려움 |
| 핵심 솔루션 | 자연어 검색 + 지도 기반 시각화 + 3D 공간 확인 + AI 추천 통합 |
| 타겟 유저 | 자취방을 구하는 대학생, 특히 타지역 거주 학생 |

## 핵심 기능 목록

| ID | 기능명 | 설명 | 우선순위 | 구현 상태 | 비고 |
|------|--------|------|:---:|:---:|------|
| F-01 | 사용자 로그인 | 사용자 로그인 정보 저장, 사용자/공급자 로그인 구분 | 중간 | ✅ | Google OAuth, SEEKER/BROKER 분리 |
| F-02 | 자연어 매물 검색 | 사용자가 자연어로 원하는 조건을 입력하면 조건 추출 및 구조화 | 높음 | ✅ | 입력·전달 구현, 조건 추출/구조화는 백엔드 담당 |
| F-03 | 매물 결과 추천 | 조건에 맞는 2~3개의 우선 매물을 점수 기반으로 추천 | 높음 | ✅ | TOP-N 추천 표시. **매칭 점수 시각화는 미구현(정책상 제외)** |
| F-04 | 지도 시각화 | 추천 매물과 주변 인프라를 지도에 마커로 표시 | 높음 | ✅ | T-map 실연동. 매물 비교(F-13)도 지도 마커로 충족 |
| F-05 | 인프라 필터링 | 편의점, 헬스장, 카페, 학교 출입문 등 생활 인프라 필터 제공 | 높음 | ✅ | T-map POI 실연동, 카테고리/반경 필터 |
| F-06 | 경로 안내 | 선택한 매물에서 학교/특정 시설까지 최적 경로 및 소요시간 제공 | 높음 | ✅ | 추천 경로 geometry + T-map 보행경로 보강 |
| F-07 | 3D 공간 보기 | 특정 매물 선택 시 3D 모델을 통해 방 구조를 확인 | 높음 | ✅ | Spline 뷰어 실연동 |
| F-08 | 매물 상세 정보 조회 | 주소, 면적, 구조, 가격, 사진, 중개사 연락처 등 제공 | 높음 | ✅ | 중개사 연결은 데모 모달(연결 준비 중 안내) |
| F-09 | AI 추천 설명 | "왜 이 매물이 추천되었는지"를 자연어로 설명 | 높음 | ✅ | 표시 구현, 설명 내용은 백엔드 생성 |
| F-11 | 동적 인프라 정보 조회 | DB에 없는 정보는 외부 지도 API 연동으로 실시간 조회 | 중간 | ✅ | 매물 상세 "주요 인프라" 하드코딩 제거, 추천 응답 기반 실제 인프라 표시 |
| F-12 | 검색 조건 수정/재검색 | 사용자가 조건을 추가·삭제하여 추천 결과를 갱신 | 높음 | ✅ | 재검색 및 추천 기록 저장으로 충족 |
| F-13 | 비교 보기 | 추천된 여러 매물을 한 화면에서 비교 | 중간 | ✅ | 지도 화면에 다중 매물 마커 표시로 충족 |
| F-14 | 공급자 기능 | 공급자 로그인 시 매물 등록 등 기능 제공 | 중간 | 🟡 | 인증·등록 구현. 수정/삭제는 백엔드 스펙 부재로 미구현 유지 |
| F-15 | 히스토리 기능 | 챗봇 대화 요약, 찜한 장소 목록 | 높음 | ✅ | AI 패널 대화 + 찜/추천 기록(마이페이지) |

## 데이터 및 외부 API 정리

| 구분 | 사용 목적 | 채택 기술/API | 적용 상태 |
|------|------|------|:---:|
| 지도/위치 데이터 | 지도 표시, 매물/인프라 시각화, 위치 검색 | **T-map** (지도 SDK + POI 검색) | ✅ 적용 |
| 도보 경로 렌더링 | 매물 추천 시 경로 시각화 | **T-map 보행자 경로 API** | ✅ 적용 |
| 대중교통/경로 | 통학 경로, 소요시간 계산 | 추천 응답의 경로 geometry(백엔드) + 구간 보강 | ✅ 적용 |
| 자연어 처리 | 자연어 검색 조건 추출 및 구조화 | 백엔드 LLM 연동(GPT/Claude) | ➖ 백엔드 담당 |
| DB/공간검색 | 매물 저장, 거리 계산, 반경 검색, 추천 | 백엔드(PostgreSQL/PostGIS 등) | ➖ 백엔드 담당 |
| 3D 자산 | 방 구조 3D 시각화 | **Spline** (`<spline-viewer>` 웹 컴포넌트) | ✅ 적용 |

## 사용자 유형별 진입 흐름

- **일반 사용자(SEEKER)**: S-00 로그인 → S-01 온보딩(최초 1회) → S-02 메인 지도 → 검색/추천/상세 탐색 → S-11 마이페이지에서 저장 정보 확인
- **공급자(BROKER)**: S-00 관리자 로그인 → 중개사 인증(사업자등록번호 + 서류 제출) → 심사 대기 → 승인 후 A-01에서 매물 등록
